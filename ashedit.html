Tools
PSwitch to the pencil tool (RMB to pick tile)
FSwitch to fill tool (Alt for clear fill, Ctrl for non-contiguous, RMB to test visible layers)
CSwitch to the clear tool (Shift clears all layers)
SSwitch to the solids tool
KSwitch to the clone tool
VSwitch to the layer mover tool
MSwitch to the macro tool
RStart/stop recording a macro
Selection
QSwitch to the marquee tool (Shift to add, Alt to subtract)
WSwitch to the magic wand tool (Shift to add, Alt to subtract, Ctrl for non-contiguous, RMB to test visible layers)
Ctrl+ASelect all
Ctrl+DSelect none
Ctrl+Shift+IInvert selection
Ctrl+CCopy (Shift for all layers)
Ctrl+XCut (Shift for all layers)
DeleteDelete (Shift for all layers)
Ctrl+VPaste
Groups
GAdd a group (using marquee)
Alt+GDelete a group (using marquee)
Visibility
TToggle current layer drawing
Ctrl+TToggle current layer solids drawing
Quick Access
F1→F12Jump to layer/Toggle layer visibility
1→0Set the scale factor
Resizing
Ctrl+LeftInsert a column at the cursor
Ctrl+RightInsert a column after the cursor
Alt+XDelete the column at the cursor
Ctrl+UpInsert a row at the cursor
Ctrl+DownInsert a row after the cursor
Alt+YDelete the row at the cursor
Alt+UpInsert a layer before the current layer
Alt+DownInsert a layer after the current layer
Alt+LDelete the current layer
File
Ctrl+NStart a new map
Ctrl+OOpen a map
Ctrl+SSave the map
Ctrl+Shift+SSave the map with a new name
Undo/Redo
Ctrl+ZUndo
Ctrl+YRedo
Miscellaneous
EnterSave a screenshot as PNG (AshEdit-Screenshot-####.png)
